Publicar Camada (GeoServer)

Enviar sua camada do QGIS pro servidor de mapas e configurar o estilo automaticamente.

🔒 Publicar/atualizar uma camada exige login no Geohab.

1. Publicação lógica (PostGIS) vs. upload de arquivo

Se a camada selecionada já existe no banco corporativo (PostgreSQL/PostGIS), o plugin registra apenas o FeatureType no GeoServer via REST, sem tráfego de dados espaciais - é o caminho recomendado sempre que possível.

Para camadas locais (Shapefile, GeoPackage), o plugin converte e envia o arquivo via upload. É possível escolher entre Criar novo ou Sobrescrever existente.

2. Nome da camada

O nome que a camada vai ter no Geohab precisa ser idêntico ao nome da tabela no banco (é assim que o GeoServer localiza os dados). O plugin sanitiza automaticamente: minúsculas, sem espaços/acentos e sem começar com número (exigência do GeoServer).

Quando o nome é detectado automaticamente a partir da camada, o campo fica bloqueado (cadeado fechado) pra evitar divergir sem querer do nome real da tabela. Clique no cadeado pra liberar edição manual:

Pré-visualização real da interface
ℹ️ O mesmo cadeado aparece no campo Título da camada, que pode ser pré-preenchido a partir do metadado já publicado no GeoNetwork para essa camada, se houver.

3. Badge de sincronização

Funciona no mesmo espírito do badge do editor de metadados (ver níveis de verificação), comparando a configuração atual do painel com o que já está publicado no GeoServer: Sincronizado, Modificado, Não Encontrado - com a variante (DB) quando ainda não há login pra confirmar contra o servidor de verdade.

⚠️ Se o banco de dados do seu usuário estiver desconectado, o badge muda pra Erro ao verificar e um aviso aparece - reconecte a rede/VPN e tente de novo com o botão ↻ antes de continuar, pra não achar que "nada foi salvo" quando na verdade é só a checagem que falhou.

4. Atualizar Camada / Atualizar Estilo

No menu Serviços:

  • Atualizar Camada - puxa (pull) a configuração já publicada no GeoServer pro painel, sobrescrevendo o que estiver preenchido localmente. Útil quando alguém mais publicou por fora do seu QGIS.
  • Atualizar Estilo - exporta a simbologia atual do QGIS (QgsMapLayer.exportSldStyle()) como SLD e a envia como estilo padrão da camada no GeoServer.
⚠️ A conversão para SLD é best-effort: estilos complexos (regras data-driven, blending modes, efeitos de camada do QGIS) podem não ter equivalente direto em SLD 1.1.0. Revise o resultado no GeoServer depois de enviar.

5. Erros comuns

Situação Causa provável
Erro 403 ao publicar Sua conta não tem permissão de escrita no Workspace selecionado - solicite acesso ao TI.
Nome da camada rejeitado Nome começando com número ou com caracteres especiais - use o nome sanitizado sugerido pelo plugin.
SRS Nativo vazio no GeoServer Conhecido - o plugin ainda não define o CRS automaticamente na criação do FeatureType. Defina manualmente no GeoServer após publicar.
