Guia Técnico: Escala Equivalente

Como estimar o denominador da escala para um dado sem essa informação documentada.

É muito comum trabalhar com dados legados (shapefiles, CAD, etc.) sem documentação da escala original. Ainda assim, o campo Escala é importante no metadado, pois informa a precisão e o uso adequado do dado.

Este guia apresenta métodos técnicos pra estimar esse valor de forma retroativa, baseando-se na Resolução Espacial (dados raster) e na Acurácia Posicional (dados vetoriais).

1. Para dados raster (imagens, ortofotos)

A escala é derivada do GSD (Ground Sample Distance), o tamanho de cada pixel no mundo real. A regra de bolso da cartografia, baseada na acuidade visual humana (0,2mm a 0,5mm no papel), dá uma fórmula simples e segura:

📐 Escala Equivalente ≈ Tamanho do Pixel (em metros) × 2.000 (considerando uma acuidade conservadora de 0,5mm)
  • Exemplo 1: pixel de 50 cm (0,5 m). Cálculo: 0,5 × 2.000 = 1.000 → escala equivalente 1:1.000.
  • Exemplo 2: imagem de satélite com pixel de 10 m. Cálculo: 10 × 2.000 = 20.000 → escala equivalente 1:20.000 (ou 1:25.000, sendo mais conservador).

2. Para dados vetoriais (pontos, linhas, polígonos)

Para vetores, analisa-se a precisão da coleta ou a generalização do desenho.

Método A - pelo erro posicional conhecido (PEC)

Se você sabe a acurácia do equipamento que coletou os dados (ex.: GPS de navegação, RTK), use a fórmula reversa do Padrão de Exatidão Cartográfica (PEC), considerando um erro gráfico aceitável de 0,2mm no mapa:

📐 Escala = Erro Real (em metros) / 0,0002
  • Cenário 1: GPS de mão, erro de 5 m. Cálculo: 5 / 0,0002 = 25.000 → 1:25.000.
  • Cenário 2: GPS RTK, erro de 10 cm (0,10 m). Cálculo: 0,10 / 0,0002 = 500 → 1:500.

Método B - pela generalização (teste visual no QGIS)

Se a precisão é desconhecida, use a comparação visual:

  1. Adicione sua camada vetorial no QGIS.
  2. Adicione um mapa base de alta resolução por baixo (ex.: Google Satellite).
  3. Dê zoom em uma feição curva bem definida (um rio, uma rua).
  4. Observe a escala exibida no QGIS no momento em que a linha do seu dado começa a parecer "quadrada", simplificada demais ou descolada da realidade do mapa base - essa escala é uma boa estimativa da escala original.

3. O que escrever no plugin

No campo Escala, insira o denominador estimado (ex.: 25000).

Documente como você chegou a esse número no campo Resumo, com uma nota honesta como:

📝 "Escala original de produção não documentada. O denominador de escala (1:XX.XXX) foi estimado com base na [acurácia posicional conhecida / comparação visual com ortofotos], considerando uma precisão estimada de [X] metros."
