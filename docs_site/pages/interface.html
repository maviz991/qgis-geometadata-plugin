Visão Geral da Interface

Como a janela do plugin é organizada e o que cada área faz.

1. Cabeçalho (barra de ações)

Fica sempre visível no topo da janela, com três menus:

Menu Ações
Arquivo Continuar Depois, Descartar Alterações - ações genéricas, funcionam tanto no editor de metadados quanto no painel do GeoServer, o que estiver aberto.
Catálogo Editor de Metadado, Baixar Metadado (busca no Geohab), Importar Metadado, Exportar Metadado, Publicar Metadado (envia pro Geohab) - tudo específico de metadados (GeoNetwork).
Serviços Configurar Camada, Publicar Camada, Baixar Camada (traz do GeoServer), Atualizar Estilo - específico de publicação de camadas (GeoServer).

No canto direito ficam o seletor de camada ativa, o badge do usuário logado (clique para sair) e o botão Entrar.

2. Home

Tela inicial do plugin, com um card de acesso rápido para cada módulo:

Pré-visualização real da interface

Catálogo Geohab abre o editor de metadados (GeoNetwork); Serviços Geohab abre a publicação de camadas (GeoServer); Documentação é este manual.

Badge "Ativo/Instável/Offline"

Cada card mostra o status do servidor correspondente, checado automaticamente ao abrir a Home - sem precisar estar logado:

Pré-visualização real da interface
⚠️ Offline aqui significa que o plugin não conseguiu conectar ao servidor - confira sua VPN e conexão de rede antes de abrir um chamado. Instável significa que o servidor respondeu, só que de um jeito inesperado (não é necessariamente um problema).

Se você ainda não estiver logado, a Home mostra um aviso no topo lembrando que algumas funções exigem login:

Pré-visualização real da interface

3. Seletor de camada ativa

O formulário do editor e o painel do GeoServer sempre trabalham em cima da camada selecionada no painel de camadas do QGIS. O badge no cabeçalho mostra o nome da camada ativa e permite trocar rapidamente sem sair do plugin.

4. Tema claro/escuro

O plugin detecta o tema do QGIS na inicialização e se adapta automaticamente. Se você mudar o tema do QGIS com o plugin já aberto, reinicie o QGIS para que o plugin acompanhe a mudança.
